```

```

## 📺 MONITORING

Just watch the terminal where OpenBR runs.

Every HRMS request shows as:
```
127.0.0.1 - - [TIMESTAMP] "METHOD /PATH HTTP/1.1" STATUS_CODE -
```

- `200` = Success ✅
- `401` = Auth failed ❌
- `500` = Server error ❌
